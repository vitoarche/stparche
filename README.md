# STP&ARCHE Bot

Advanced Discord Music & Moderation Bot.

## Features
- **Music**: High-quality music playback from YouTube (custom extractor) and Spotify.
- **Moderation**: Kick, Ban, Timeout, and logging.
- **Leveling**: XP sytem with rank cards.

## Setup
1. Clone repository.
2. `npm install`
3. Configure `.env`
4. `npm run dev`
